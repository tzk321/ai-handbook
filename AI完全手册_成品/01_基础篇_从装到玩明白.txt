这份手册是给"完全没接触过"的人写的。
不用懂电脑，不用懂英文，照着点就行。

────────────────────────────
怎么用这份手册
────────────────────────────
· 只想先聊上天 → 看【第 1 篇】和【第 2 篇】，别的都别看。
· 想让它有性格、像个人 → 看【第 3 篇】【第 4 篇】。
· 想玩花的（世界书、技能） → 看【第 5 篇】【第 6 篇】。
· 想让它帮你干活（读写文件、跑命令） → 看【第 7 篇】。
· 出错了 → 直接翻【第 9 篇】对号入座。
· 看不懂的词 → 【第 10 篇】有词典。

规矩一条：下面凡是让你"打这几个字"的，一个字都别改。
大小写、斜杠、小数点全都要一样。能用复制，就别手打。


╔══════════════════════════════════════════════════════╗
║ 第 1 篇 · 装 + 让它开口（最重要，先干这个）           ║
╚══════════════════════════════════════════════════════╝

━━ 1.1 装 app ━━
1. 点开我发你的安装包（文件名结尾是 .apk）
2. 手机问"是否安装这个应用" → 点【安装】
3. 如果它说"不允许安装未知应用"：
   点它给的【设置】→ 打开那个开关 → 退回去再点一次【安装】
4. 装完，桌面多一个图标。点开。

━━ 1.2 找"设置" ━━
打开 app，找【设置】两个字（也可能是个齿轮小图标）。
一般在上边或下边那一排按钮里。

👉 如果一打开就弹出"请配置API和模型" —— 那就是在催你，点进去。

━━ 1.3 加一个"供货商"（专业词：提供商） ━━
它就是"卖脑子给你的商家"。

1. 设置里找【提供商】→ 点进去
2. 点右下角【＋】或【添加提供商】
3. 会出现几个空格，一个一个填：

   ◆【名称】随便打，比如：我的AI
     （只是给自己看，不影响任何东西）

   ◆【类型】看到就选【OpenAI】。看不懂就挑名字里带 OpenAI 的。
     （硅基流动、智谱、DeepSeek 都是这一挂）没有这一格就跳过。

   ◆【API Base Url】（有的只写 Base Url）
     打这一串，一个符号都别少：
        https://api.siliconflow.cn/v1

   ◆【API Key】
     把网页上那串密码（长得像 sk-abcdefg……）整段粘进来。
     ⚠️ 从第一个字母粘到最后一位，前边别带空格。

4. 点右上角【保存】或【✓】

━━ 1.4 加一个"型号"（专业词：模型） ━━
只有商家不行，还得挑具体型号，不然它不知道用哪个脑子说话。

1. 还在刚才那页，往下找【模型】这一块
2. 点【添加模型】
3. 又给你几个格子：

   ◆【模型ID】← 最重要，十个错有九个错在这
     去你注册的网站，找【模型广场】或【模型列表】，
     找到要用的那个，把名字整段复制过来。
     它长得像这样：
        deepseek-ai/DeepSeek-V3
     或者这样：
        glm-4-flash
     （别手打，复制）

   ◆【模型显示名称】随便打，比如：小助手
   ◆【模型类型】选【聊天】

4. 保存

━━ 1.5 说话 ━━
1. 退回聊天页
2. 点【新对话】（或右下角 ＋）
3. 上面能选助手／模型，选刚建的"小助手"
4. 框里打两个字：你好
5. 发送

它回你了 —— 成了。

━━ 1.6 那串密码（API Key）去哪拿？ ━━
⚠️ 先试最省事的：有些 app 里自带一个叫【RikkaHub】的供货商，
不要密码、不用申请。去【提供商】列表里翻一翻，有就点它，跳到 1.5。

列表里没有，就自己申请（免费，五六分钟）：
1. 手机浏览器打开：cloud.siliconflow.cn
2. 手机号注册、登录
3. 会让你实名认证（拍身份证，很快）。不实名就没有免费额度
4. 左边菜单找【API 密钥】→ 点【新建】→ 给你一串 sk- 开头的字
5. 🚨 这串东西只显示这一次！马上复制、马上粘到 1.3 的格子里。
   忘了也没事，回去再新建一串。


╔══════════════════════════════════════════════════════╗
║ 第 2 篇 · 会聊天（日常用得最多）                      ║
╚══════════════════════════════════════════════════════╝

━━ 2.1 家在哪 ━━
· 【新对话】：开一个新话题（右下角 ＋）
· 【聊天历史】：以前聊过的都在这。能搜索、能置顶、能删
· 【设置】：所有配置都在这

━━ 2.2 怎么换脑子（换模型） ━━
两条路：
· 临时换：在对话页面上面点一下模型名字，挑一个
· 永久换：设置 → 助手 → 点进某个助手 →【聊天模型】
  （助手不设的话，就用【设置 → 默认模型和提示词】里的全局默认）

━━ 2.3 两个参数，记住比喻就行 ━━
·【温度】：想象力。调低（0.2）= 一本正经、答案稳定；
  调高（1.0 以上）= 天马行空、每次都不同。写代码调低，写故事调高。
·【最大Token数】：一次最多写多少字。留空 = 不限，但可能一顿狂写花你钱。

━━ 2.4 聊太长了怎么办 ━━
对话顶上有个【压缩历史】。它把前面几百句话揉成一段摘要，
这样后面继续聊不会又贵又卡。
⚠️ 压缩会重置当前对话里的消息，重要的事先说一声。

━━ 2.5 能发图吗？ ━━
能。聊天框旁边有加号，可以发图片、发文件。
前提：你用的那个模型得支持"看图"（挑模型时看它有没有"图片"能力）。

━━ 2.6 别的杂事 ━━
· 想改聊天背景：助手设置 →【聊天背景】
· 想让它念出来：设置 →【语音服务】（TTS）
· 想用电脑看：设置 →【Web服务器】（同一个 WiFi 下，手机变网站）


╔══════════════════════════════════════════════════════╗
║ 第 3 篇 · "助手"是什么（人设）                        ║
╚══════════════════════════════════════════════════════╝

一句话：**助手 = 你雇的那个人**。
每个助手有自己的名字、性格、说话方式、用哪个模型、记得什么。

你可以在【设置 → 助手】里雇好几个：
一个帮你干活的、一个陪你聊天的、一个教书的，互不打扰。

━━ 3.1 新建一个助手 ━━
设置 →【助手】→ 右下角 ＋
然后能填这些（不用全填）：

·【助手名称】比如：老王
·【头像】点一下能换图片
·【聊天模型】这个助手固定用哪个模型
·【预设聊天消息】就是开场白。AI 一出场先说的那句话，你写啥它说啥

━━ 3.2 点进助手以后，里面分了几个块 ━━
（这些名字在 app 里就是这么写的）

·【基本】名称、头像、模型、参数（温度那些）
·【提示词】写"它是谁"（重点，第 4 篇讲）
·【扩展管理】世界书、模式注入、快捷消息、技能（第 5、6 篇讲）
·【本地工具】让它能用 JavaScript、剪贴板、时间等（第 7 篇讲）
·【记忆】让它记住你
·【MCP】接外部服务
·【请求配置】改请求头、请求体（不懂别动）

━━ 3.3 小技巧 ━━
· 觉得改废了：【复制】一下留个备份，再改新的
· 想删：【删除】（删了就没了，问一下再删）
· 想让所有对话共用一个"总人设"：把默认助手设成你常用的那个


╔══════════════════════════════════════════════════════╗
║ 第 4 篇 · 提示词（决定它像不像人）                    ║
╚══════════════════════════════════════════════════════╝

━━ 4.1 提示词写在哪个框 ━━
设置 →【助手】→ 点进那个助手 →【提示词】→ 找到【系统提示词】那一大框。
写进去，保存。以后这个助手就按这套活。

⚠️ 最容易犯的错：
在聊天框里说"你要像个毒舌兄弟" —— 那只是聊了两句，重启就忘了。
**要它变成什么，必须写进【系统提示词】。**

━━ 4.2 一句口诀：谁 + 怎么说话 + 不许干什么 ━━

  ① 你是谁（身份、年龄、跟我的关系）
  ② 你怎么说话（语气、句子长短、口头禅、用不用表情）
  ③ 你不许干什么（别讲大道理、别用书面语、别一次写太长）

三段写清楚，比写一千字花里胡哨的有用。

━━ 4.3 可以直接抄的 5 个模板（见最后【附录A】） ━━

━━ 4.4 可以插的"变量"（写提示词时能用） ━━
它们会在说话时自动变成真实内容：

  {{char}}        这个助手的名字
  {{user}}        你的名字
  {{time}}        现在几点
  {{cur_date}}    今天几号
  {{weekday}}     星期几
  {{timezone}}    时区
  {{locale}}      语言地区
  {{model_name}}  正在用哪个模型
  {{device_info}} 手机型号之类的信息

例：在提示词里写"现在是 {{time}}，跟 {{user}} 说话别啰嗦"，
它就知道几点了。

━━ 4.5 另外两个框（不填也行） ━━
·【聊天内容模板】：控制每条消息怎么打包送出去，不懂别动（有默认的）
·【正则】：自动替换／删掉回复里的某些字，进阶玩法


╔══════════════════════════════════════════════════════╗
║ 第 5 篇 · 世界书 · 模式注入 · 快捷消息                 ║
╚══════════════════════════════════════════════════════╝

这三个都在：设置 →【扩展管理】（也能从助手里进）。

━━ 5.1 世界书（Lorebook） = 一本"关键词词典" ━━
作用：平时不占地方，只要你提到了某个词，它就把对应的那几句话塞给 AI。
适合记设定：人物的经历、地名的来历、你的喜好、某个圈子的黑话。

怎么建：
【扩展管理】→【世界书】→ 添加世界书 → 进去 → 添加条目

条目里几个格子（app 里就这么叫）：
·【关键词】触发词。提到这些词才生效（可以写多个）
·【注入内容】要告诉它的话
·【常驻激活】打开 = 不管提不提，永远塞进去
·【注入位置】放哪儿：系统提示词前／系统提示词后／对话开头／最新消息前
·【注入深度（消息数）】塞进最近第几条消息的位置
·【优先级】数字越大越优先
·【大小写敏感】英文才需要管

怎么用：助手 →【扩展管理】→【世界书】→ 勾上你要的那本

━━ 5.2 模式注入 = 一整段固定的话 ━━
比如你写一段"深夜模式：说话要轻，别提工作"，
需要的时候打开，不需要关掉。就这么简单。

━━ 5.3 快捷消息 = 常用短语 ━━
经常要说的话（"继续""说人话""重新写"）存起来，
聊天时一点就发，不用每次打。

━━ 5.4 三者怎么挂到助手上 ━━
助手 →【扩展管理】→ 上面有 4 个页签：
【世界书】【模式注入】【快捷消息】【Skills】
点进去勾选就行。勾了才算这个助手的。


╔══════════════════════════════════════════════════════╗
║ 第 6 篇 · 技能 Skill（这是最好玩的部分）              ║
╚══════════════════════════════════════════════════════╝

一句话：**提示词是"性格"，技能是"手艺"。**
技能就是给 AI 的一本操作手册 —— 里面写着"遇到什么活该怎么干"，
它需要的时候自己翻开看。

━━ 6.1 技能长什么样 ━━
一个文件夹，里面至少有一个文件叫：SKILL.md
SKILL.md 开头必须有两行是：

  ---
  name: 技能名
  description: 一句话说清"什么时候该用这个技能"
  ---

下面才是正文（怎么干活的步骤）。
description 写得好不好，直接决定它会不会想起来用。

━━ 6.2 怎么装技能（三种，按简单程度排） ━━

【方法一 · 从 GitHub 导入】← 推荐，最省事
1. 设置 →【扩展管理】→ 找到【Agent Skills】（管理可供 AI 按需加载的技能包）
2. 点右下角【＋】→【从 GitHub 导入】
3. 粘上仓库地址（它会自动下载仓库根目录的 SKILL.md）
4. 看到"技能已导入：xxx"就成了

【方法二 · 直接粘贴】
1. 同一页 →【＋】→ 粘贴 SKILL.md 的全部内容
2. 它会自己读开头的 name，读不到会报"找不到名称字段，请检查 frontmatter 格式"

【方法三 · 自己写】
在技能详情页有【新建文件】【编辑】【保存】：
文件名写 SKILL.md，内容按 6.1 的格式写。
写完存，一个技能就诞生了。

━━ 6.3 怎么让它用上 ━━
技能装好了不等于开着。
助手 →【扩展管理】→【Skills】页签 → 把要用的勾上。
（没勾 = 这个助手看不见这本手册）

━━ 6.4 技能能干啥（举几个例子） ━━
· 让它按固定格式写日报、周报
· 让它帮你看图、按规矩改图
· 让它记账、算账、按你的模板出表
· 让它帮你查资料、按你的格式整理
· 让它按某套流程跟客户/朋友说话

━━ 6.5 去哪找现成的技能 ━━
· GitHub 搜：rikkahub skill、SKILL.md、claude skills
· 别人分享的 GitHub 仓库，直接【从 GitHub 导入】
· ⚠️ 只装你看得懂的。技能是能让 AI 动你文件、跑命令的东西，
  来路不明的最好先打开 SKILL.md 看一眼里面写了啥。

━━ 6.6 让 AI 自己写技能 ━━
跟它说："把刚才这套流程写成一个技能，包含 name、description
和操作步骤，按 SKILL.md 的格式给我"。
它写完，你把内容粘到 6.2 方法二里，存上，就能复用了。


╔══════════════════════════════════════════════════════╗
║ 第 7 篇 · 让它动手干活（进阶，先会用聊天再来）         ║
╚══════════════════════════════════════════════════════╝

━━ 7.1 内置小工具 ━━
助手 →【本地工具】，可以一个个打开：
· JavaScript 引擎：让它算数、跑小脚本（QuickJS）
· 时间信息：让它知道今天几号、星期几、几点、什么时区
· 剪贴板：读／写你手机复制的东西
· 询问用户：允许它反过来问你问题（"你要哪种格式？"）
· 文字转语音：用 TTS 念出来
· 注意：这些要模型支持"工具调用"才好使（挑模型时看能力）

━━ 7.2 工作区（让它有文件、有系统） ━━
设置里的【工作区】：
· 给它一个专属文件夹，它能【列出文件】【读取】【写入】【编辑】【移动】【删除】
· 还能【安装 Rootfs】+【启用 Shell】——
  相当于手机里塞了个小 Linux，它能真的跑命令干活
·【工具审批】打开后，它每次动手之前都要你点同意（建议先开着，看着放心）
· 终端那里能自己敲命令（装了 Rootfs 才有）

━━ 7.3 记忆 ━━
助手 →【记忆】：打开以后，它聊天时会主动把关于你的事记下来，下次还能用。
·【全局记忆】：所有助手共用一份记忆（不开就是每个助手各记各的）
· 需要模型支持工具调用
· 想看看它记了啥：助手 →【记忆】里能翻、能改、能删

━━ 7.4 MCP ━━
设置 →【MCP】：接外面做好的工具服务（进阶玩家玩，先跳过没关系）

━━ 7.5 搜索 ━━
设置 →【搜索服务】：让 AI 能上网查（要单独配一个搜索服务商）

║ 第 8 篇 · 备份 · 省钱 · 保命                          ║
╚══════════════════════════════════════════════════════╝

━━ 8.1 备份 ━━
设置 →【数据备份】：备份和恢复应用数据。
换手机、手滑删东西之前，先来这一下。

━━ 8.2 看它偷偷干了啥 ━━
设置 →【请求日志】：每一次请求都记着。出问题先来这看，比瞎猜强。

━━ 8.3 API Key 就是你的钱包 ━━
· 别截图发人、别发群里。别人拿到就能花你的钱
· 万一泄露了：去那个网站的"API 密钥"页面把它删掉，重新建一个

━━ 8.4 省钱的三个习惯 ━━
1. 日常闲聊用便宜的模型，办正事再换贵的
2. 一个话题聊完就开新对话（历史越长越贵）
3. 聊太长就用【压缩历史】


╔══════════════════════════════════════════════════════╗
║ 第 9 篇 · 出错了怎么办（对照表）                       ║
╚══════════════════════════════════════════════════════╝

【装的时候】
· 提示"未知来源/不允许安装"
  → 点它的【设置】，开关打开，回去再点安装
· 装了打不开、闪退
  → 删了重装。还不行就说明手机系统太老，换台手机

【配置的时候】
· 401 / Invalid API Key / 密钥无效
  → 那串密码不对。重新复制，注意别带空格
· 404 / Not Found
  → Base Url 打错了，结尾必须是 /v1
· 402 / 余额不足 / insufficient balance
  → 没钱了。换免费模型，或去网站充点钱
· 400 / 模型不存在 / model not found
  → 模型ID 打错了。回网站复制，别手打
· 一直转圈、不出字

· API —— 程序之间说话的通道。你不用管，知道"要填"就行
· API Key —— 一串密码（sk- 开头）。它就是你的门禁卡，也是你的钱包
· Base Url —— 网站地址。填错了它找不到人
· 提供商（供应商）—— 卖 AI 服务的商家
· 模型 —— 具体的脑子型号。同一家商家有贵的有便宜的有聪明的
· Token —— 计费单位，大概一个汉字一个多。字越多越贵
· 上下文 —— 它一次能记住的内容长度。太长会忘、会贵
· 温度 —— 想象力大小（0 老实，1 以上放飞）
· 系统提示词 —— 它的"人设说明书"。最重要的一个框
· 助手 —— 你雇的那个人，带自己的人设和配置
· 世界书 —— 关键词触发的设定词典
· 模式注入 —— 一整段固定的话，开关控制
· 技能 Skill —— 给它的操作手册，写着"遇到什么活怎么干"
· 工作区 —— 给它的文件夹（甚至一个 Linux 小系统）
· MCP —— 接外面工具的插口，进阶的
· 压缩历史 —— 把长对话揉成摘要，省 token

【A-3 温柔恋人】

你是我的家教，教的是我不熟的科目。
规则：
1. 先问我哪一步不懂，别一口气讲到底

不准的地方我自己会知道，你不用保证准。

- 不许编我没说的事
- 句子短，一条不超过 20 字
- 别加"加油""继续保持"这类废话
