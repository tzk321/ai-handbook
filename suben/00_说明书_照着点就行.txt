【AI 说明书 · 照着点就行】

先说一条规矩：
凡是下面让你"打这几个字"的地方，一个字都别改。
大小写、斜杠、小数点，全都要一样。能用复制就别用手打。

════════════════════════
━ 第一步 · 把这个 app 装上
════════════════════════
1. 点开我发你的那个安装包（文件名最后是 .apk）
2. 手机会问"是否安装这个应用" → 点【安装】
3. 如果它说"不允许安装未知应用"：
   点它给的【设置】→ 打开那个开关 → 退回再点一次【安装】
4. 装完，桌面上多出一个图标。点开它。

════════════════════════
━ 第二步 · 找到"设置"
════════════════════════
打开 app 以后，先找【设置】两个字（也可能是一个齿轮小图标）。
一般在上边或者下边那一排按钮里。

👉 如果一打开就弹出一句"请配置API和模型" —— 别慌，那就是设置，点进去。

════════════════════════
━ 第三步 · 加一个"供货商"
════════════════════════
（这个东西叫"提供商"，就是卖 AI 的那个商家）

1. 设置里找到【提供商】，点进去
2. 点右下角的【＋】或者【添加提供商】
3. 会出现几个空格让你填，一个一个来：

   ◆【名称】
     随便打，比如：我的AI
     （这个就是给名字，不影响任何东西）

   ◆【类型】
     看到这一格就选【OpenAI】。看不明白就挑名字里带 OpenAI 的。
     （硅基流动、智谱、DeepSeek 都是这一挂的，放心）
     没有这一格，跳过。

   ◆【API Base Url】（有的只写 Base Url）
     打这一串，一个符号都别少：

       https://api.siliconflow.cn/v1

   ◆【API Key】
     把网页上那串密码（长得像 sk-abcdefg……）整段粘进来。
     ⚠️ 从第一个字母粘到最后一位，前边别带空格。

4. 点右上角的【保存】或【✓】

════════════════════════
━ 第四步 · 加一个"型号"
════════════════════════
光有供货商不行，还得挑一个具体型号，不然它不知道用哪个脑子跟你说话。

1. 还在刚才那个页面，往下找到【模型】这一块
2. 点【添加模型】
3. 又给你几个格子：

   ◆【模型ID】  ← 最重要，十个错有九个错在这
     去你注册的那个网站，找【模型广场】或【模型列表】，
     找到你要用的那个，把名字整段复制过来。
     它一般长这样：
       deepseek-ai/DeepSeek-V3
     或者这样：
       glm-4-flash
     （别手打，复制）

   ◆【模型显示名称】
     随便打，比如：小助手

   ◆【模型类型】
     选【聊天】

4. 保存

════════════════════════
━ 第五步 · 让它开口
════════════════════════
1. 退回聊天那个页面
2. 点【新对话】（或者右下角的 ＋）
3. 上面有个地方能选助手／模型，选你刚建的那个"小助手"
4. 最下面那个框里打两个字：你好
5. 发送

它回你了 —— 成了。

════════════════════════
那串密码（API Key）去哪拿？
════════════════════════
⚠️ 先试最省事的：
有些 app 里本来就自带一个叫 【RikkaHub】 的供货商，不要密码、不用申请。
去【提供商】列表里翻一翻，有就点它，直接跳到第五步。

列表里没有，就自己申请一个（免费，五六分钟）：
1. 手机浏览器打开：cloud.siliconflow.cn
2. 手机号注册、登录
3. 它会让你实名认证（拍身份证，很快）。不做实名就没有免费额度
4. 左边菜单找【API 密钥】→ 点【新建】→ 会给你一串 sk- 开头的字符
5. 🚨 这串东西只显示这一次！马上复制、马上粘贴到第三步那个格子里。
   忘了也没事，回去再新建一串就行。

════════════════════════
崩了？对着找
════════════════════════
・提示 401 / Invalid API Key / 密钥无效
  → 那串密码不对。重新复制一遍，注意别带空格

・提示 404 / Not Found
  → Base Url 打错了。结尾必须是 /v1

・提示 402 / 余额不足 / insufficient balance
  → 没钱了。换个免费模型，或者去网站充值

・一直转圈、不出字
  → 网络的事。关了重开试试；还不行就是网站那边在卡

・找不到模型 / 列表是空的
  → 模型ID 打错了。回网站复制，别自己敲

・让我选"类型"，可那些英文我一个都不认识
  → 选 OpenAI，就它
